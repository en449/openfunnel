Add a mapping
Host Funnel
Still needed outside this console
  1. Map it here first, then add it in Vercel. A hostname this console does not know is treated as a console hostname — so a domain attached in Vercel before it is mapped here serves this console on your client's domain until you map it.
  2. Add the domain to this project in the Vercel dashboard.
  3. Have the client point DNS at it: an A record for an apex domain (e.g. client-firma.de), or a CNAME for a subdomain (e.g. angebot.client-firma.de).
  4. Use the exact value Vercel's own domain card shows for THAT domain — those values are per-project and change over time, so copy them fresh from Vercel, never from a document like this one.
